X API connection

Create an app at developer.x.com with Read and Write permissions. This deployment can post through either OAuth 1.0a (API key + access token) or OAuth 2.0 (Client ID + Secret, PKCE). Pay-per-use billing applies (~$0.015/post, ~$0.20 if the post contains a link).

  1. In the X app → User authentication settings, add the redirect URI below.
  2. Give the app Read and write permission with scopes tweet.read, tweet.write, users.read, offline.access.
  3. Save the Client ID/Secret here, then Connect with X and authorize.
